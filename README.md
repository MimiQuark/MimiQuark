## 统一口径

- **项目类型**区分个人项目、团队项目与毕业设计，不将团队成果全部归为个人成果。
- **本人角色**只描述本人负责的模块。
- **项目规模**优先使用数据量、系统模块、接口或测试数量等可核对信息。
- **验证状态**区分代码实现、样例运行、真实数据评估与完整实验。
- **公开边界**明确数据、权重、源码不能公开或尚未复现的部分。
- **代码范围**仅提供项目说明，不公开底层实现、数据集、模型权重或部署材料。
